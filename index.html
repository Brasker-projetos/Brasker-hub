Firebase não configurado
Para que os dados sejam compartilhados entre dispositivos, você precisa configurar o Firebase.

Como fazer:
1. Acesse console.firebase.google.com
2. Crie um projeto → Realtime Database → Criar banco
3. Nas Regras, cole: {"rules":{".read":true,".write":true}}
4. Vá em Configurações do projeto → Seus apps → Configuração
5. Substitua os valores em FIREBASE_CONFIG no HTML
